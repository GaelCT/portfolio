Pothole In Progress

Next.js TypeScript SQLite YOLO Label Studio

Pothole is a detection and mapping platform that turns road photos into prioritized maintenance reports. A YOLO detector trained on 300 road images annotated in Label Studio identifies potholes from images, and a Next.js + TypeScript + SQLite pipeline pairs each detection with GPS coordinates and street descriptions.

Detections are assembled into city-service request drafts ready for manual filing. Dashcam capture and live model integration are in active development.

Key Features

  • • YOLO detection trained on 300 hand-annotated road images
  • • Reporting pipeline pairing photos, GPS coordinates, and street descriptions
  • • City-service request drafts ready for manual filing
  • • In progress: dashcam capture and live model integration

Technical Challenges

The work so far has focused on getting reliable detection from a modest 300-image annotated dataset, keeping the report schema clean enough for city workflows, and shaping the pipeline so dashcam footage can plug in without rework.
