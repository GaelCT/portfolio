PythonProjectASL

Python Git Jupyter Notebook

PythonProjectASL is a Python-based project centered on American Sign Language (ASL), combining accessible technology with hands-on programming practice.

This project explores working with ASL data using Python, covering fundamentals like data handling, scripting, and visualization. It was developed as part of my coursework at California State University, Bakersfield.

Through this project I strengthened my problem-solving skills and gained practical experience writing clean, well-structured Python code, using Git for version control throughout development.
