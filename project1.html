PythonProjectASL

Python OpenCV MediaPipe scikit-learn Qwen + LM Studio

PythonProjectASL is a real-time American Sign Language (ASL) recognition and text-correction system. At its core is a Random Forest classifier trained on a self-collected MediaPipe landmark dataset of approximately 32,000 rows across 24 feature columns, reaching an estimated 60–70% recognition accuracy.

Gesture timing introduces noise — missed letters, accidental spaces — so raw predictions pass through a local text-correction layer powered by Qwen running in LM Studio. Gesture shortcuts handle dynamic ASL letters that static landmarks alone can't capture.

Everything runs locally on the machine: no frames or transcripts are sent anywhere, which keeps the pipeline fast, private, and free to operate.
