Inventory Management System

Python Flask SQLite REST API

A comprehensive inventory management system designed to streamline warehouse operations and track product movement in real-time. This application addresses the common challenges of manual inventory tracking by providing automated stock level monitoring, expiration date tracking, and supplier management.

Key features include barcode scanning integration for quick item identification, low stock alerts via email notifications, and a dashboard with real-time analytics on inventory turnover. The system supports multiple warehouse locations and includes role-based access control for admin, manager, and staff users.

Built as a capstone project for my Software Engineering course, this application demonstrates full-stack development capabilities using Python Flask for the backend API and vanilla JavaScript for the frontend. The SQLite database is optimized for fast queries and the REST API follows best practices for HTTP methods and status codes. The project includes comprehensive unit tests and documentation, showcasing my commitment to code quality and maintainability.
