ChatBranch

TypeScript GitHub API OAuth JSON Schema

ChatBranch is an AI-assisted developer tool that structures LLM output into strictly parseable JSON for GitHub workflow automation. Built to help students manage branching, commits, and pull requests through natural language instead of memorizing git commands.

The core challenge was designing a JSON schema that LLMs could reliably produce — enabling deterministic parsing without external API calls. This meant carefully crafting prompt engineering, output validation, and error recovery so the tool works consistently across different model outputs.

Key technical areas: GitHub REST/GraphQL API integration (repos, branches, commits, PRs), OAuth authentication flow with token management, JSON schema design for structured LLM output, and a CLI interface that translates natural language into git operations. Early users include CSUB students adopting it for coursework workflows.

Developed as an architectural experiment in AI-assisted tooling — designed the data flow, auth, and API integration; generated implementation via prompting to validate the architecture. Currently iterating based on real student feedback.
